# Resumen - Clase 3: Requerimientos de Software

## ¿Qué son los requerimientos?

Los requerimientos son las necesidades, funcionalidades y restricciones que debe cumplir un sistema para resolver un problema o alcanzar un objetivo específico. Son la base para el análisis, diseño, desarrollo y pruebas del software.

## Importancia de los requerimientos

* Permiten entender qué necesita el cliente.
* Reducen errores durante el desarrollo.
* Facilitan la comunicación entre usuarios y desarrolladores.
* Sirven como guía para construir el sistema.

## Tipos de requerimientos

### Requerimientos funcionales

Describen lo que el sistema debe hacer.
Ejemplos:

* Registrar usuarios.
* Generar reportes.
* Realizar pagos en línea.

### Requerimientos no funcionales

Describen características de calidad del sistema.
Ejemplos:

* Seguridad.
* Rendimiento.
* Disponibilidad.
* Facilidad de uso.

## Proceso de análisis de requerimientos

1. Identificar necesidades.
2. Recopilar información de los usuarios.
3. Analizar y documentar requisitos.
4. Validar los requisitos con los interesados.
5. Gestionar cambios durante el proyecto.

## Beneficios

* Mejor planificación del proyecto.
* Menos retrabajo.
* Mayor satisfacción del usuario.
* Software más confiable y útil.
